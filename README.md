## Sobre o Projeto

Este repositório documenta minha jornada no **Bootcamp Corpay - Back-end do Zero a Prática**, oferecido pela **Digital Innovation One (DIO)**. 

O bootcamp aborda desde os fundamentos do Node.js até tópicos avançados como computação em nuvem com Azure e uso estratégico de Inteligência Artificial. Aqui você encontrará códigos, exercícios, anotações e projetos práticos desenvolvidos ao longo do curso.


## Grade do Bootcamp

- **Inteligência Artificial** | Uso eficiente de IA para acelerar entregas e otimizar o desenvolvimento
- **Fundamentos de Node.js** | Base sólida para construção de aplicações back-end
- **Modularização e Pacotes** | Gerenciamento de dependências e código reutilizável
- **TypeScript** | Tipagem estática, debugging e código mais seguro
- **Criação de APIs** | Desenvolvimento de APIs RESTful robustas e escaláveis
- **Azure Cloud** | Computação em nuvem, segurança e serviços essenciais |

## Tecnologias Utilizadas

- **Node.js** - Ambiente de execução JavaScript

- **Azure Cloud** - Serviços de nuvem da Microsoft
